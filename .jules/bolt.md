## 2024-10-29 - Async ListDirectory with Batching
**Learning:** When migrating synchronous file I/O to asynchronous I/O in the Node main process, using a standard `for...of` loop with `await` for each item can actually be slower and block the event loop for a similar amount of time as the synchronous code, due to the sheer overhead of microtasks. When dealing with huge directories, it is much faster and reduces maximum event loop blocking significantly to process items synchronously in batches and yield to the event loop using `await new Promise(r => setImmediate(r))` between batches.
**Action:** Use batched processing with `setImmediate` instead of `await` inside `for...of` loops for processing thousands of files concurrently without completely blocking the event loop or generating massive microtask queues.
