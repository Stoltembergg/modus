# Security policy

## Supported versions

Security fixes are prioritized for the latest published release. Please update to the latest version before reporting an issue when possible.

## Reporting a vulnerability

Please do not publish exploit details, credentials, or sensitive user data in a public issue.

Use GitHub's private vulnerability reporting for this repository if it is available: https://github.com/Stoltembergg/modus/security/advisories/new. If private reporting is unavailable, contact the repository owner privately through GitHub at https://github.com/Stoltembergg and ask for a secure reporting channel. Include the affected Modus version, impact, reproduction steps, and a way to follow up.

Do not include API keys, access tokens, private source code, or personal workspace data in a report.
