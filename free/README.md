# Reproducible glass-floor measurement (free backdrops only)

Inputs:
- `backdrops/plain-{white,cccccc,333333,black}.png`: generated by `make_backdrops.py`.
- `backdrops/photo-city-rush-cc0.jpg`: Wikimedia Commons "City rush (Unsplash).jpg" by Christopher Burns, **CC0 1.0**. Downloaded from `Special:FilePath/City_rush_(Unsplash).jpg?width=3000`; sha256 is in `photo-city-rush-cc0.sha256`, and `make_backdrops.py` checks it.

Run: `python3 make_backdrops.py && python3 ../measure.py backdrops results-free.json`

Outputs:
- `results-free.json`: P5 contrast, min and floor search per backdrop × theme × tier × text, in three modes: nosat = gate model, sat, material = reference only.
- `tables-free.md`: the same data rendered as tables.
- `after-82-89.md`: P5 at the #257 values.

Floors (gate model, the max over these backdrops):
- window: 81.5% dark / 81% light
- overlay: 88.5% dark / 76.5% light
- #245 tint: 80% / 78.5%

Same as the earlier local run, so #257's 82/89 is unchanged. An earlier run also covered vendor wallpapers (macOS Sequoia, Windows 11 Bloom). It agreed with these numbers and is not reproducible from this branch, because those files are not redistributable.
